# Araya Golf & Family Club

Website satu halaman responsif untuk Araya Golf & Family Club di Malang.

## Menjalankan secara lokal

Buka `index.html`, atau sajikan folder ini melalui HTTP (disarankan karena ikon Phosphor dimuat dari berkas JSON lokal):

```bash
python -m http.server 8000
```

Lalu kunjungi `http://localhost:8000`.

## Isi dan aset

- Tarif golf, driving range, annual golf membership, dan paket golf lesson mengikuti flyer Araya Golf 2026 yang diberikan pengguna.
- CTA reservasi, pertanyaan tarif, dan paket latihan mengarah ke WhatsApp Araya: **0811 3101 188**.
- Instagram, website, alamat, telepon, dan email Araya dicantumkan di footer.
- Logo, crop hero lapangan, foto fasilitas, dan peta memakai aset lokal dari situs resmi Araya Golf; flyer 2026 pengguna disimpan sebagai referensi tarif dan paket.
- Google Fonts DM Sans dan DM Serif Display serta ikon Phosphor disertakan lokal.
- Navigasi mobile, galeri foto, FAQ interaktif, tautan petunjuk arah, dan kartu tarif tamu khusus layar ponsel.
- Favicon, deskripsi halaman, dan structured data lokasi bisnis disertakan.
- Gaya fokus keyboard, tautan lewati navigasi, dan preferensi reduced-motion disediakan untuk aksesibilitas.
